# 回测口径

先约定、再回测，防止结论漂移。下列决策项在首次回测前逐一定死并记录依据；改口径须重跑并注明版本。

- [ ] 研究区间：____（建议覆盖一轮完整牛熊，如近 3–5 年）
- [ ] 复权方式：前复权（默认）
- [ ] 收益频率：日频收盘价 → 单标的净值序列
- [ ] 标的数量与入场方式：1–2 只；默认整笔买入，最多分 2 次进场（≤2 批）
- [ ] 资金预算：区间 1 万–1.5 万（封顶 1.5 万）；上一轮盈利→上调至接近 1.5 万，上一轮亏损→下调至接近 1 万，首次由用户在区间内选定；须过整手可买性（每仓资金 ≥ 1 手成本价，余现金计入）
- [ ] 目标收益率（卖出触发）：年化 10%；卖出点 = 除权调整后成本 ×(1+10%)^持有年数，现价 ≥ 该值即卖出
- [ ] 交易费用：佣金 ____、印花税（卖出）____、滑点 ____，依据来源 ____
- [ ] 套牢画像：历史最深回撤幅度与持续时长、从买入到回到成本价 / 达到卖出点所需时长（对照「可接受套牢约 1 年」）
- [ ] 无风险利率（仅在需要夏普等指标时）：取十年期国债到期收益率区间内均值，数据来源 ____
- [ ] 基准（对照用，非硬性）：沪深 300，对应数据 `inputs/benchmark/`
- [ ] 退出规则核验：仅当现价达年化 10% 卖出点、或出现暴雷红线（硬红线 / 基本面恶化红线）才离场；股价短期波动不触发卖出
