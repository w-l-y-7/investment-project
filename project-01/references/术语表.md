# 术语表

统一项目内术语口径。与回测口径冲突时，以 [回测口径.md](./回测口径.md) 为准。缺失的条目先标注「待补充」，不臆造定义。

| 术语 | 定义 | 备注 |
|---|---|---|
| 前复权价 | 以最新价为基准对历史价格复权，使历史价格连续可比、便于计算收益率 | 回测收益统一用前复权价 |
| 最大回撤 | 区间内净值从阶段高点回落到阶段低点的最大跌幅，衡量组合最坏的历史亏损 | 具体算法见回测口径 |
| 年化波动率 | 日收益波动率按年换算（A 股常按 √252） | 待确认是否用 √252 |
| 夏普比率 | (组合年化收益 − 无风险利率) / 年化波动率 | 无风险利率取值见回测口径 |
| 相关系数 | 两资产日收益的线性相关程度，越低分散效果越好 | |
| 基准 | 组合对照的指数，本项目默认沪深 300 | 对应数据在 inputs/benchmark/ |
