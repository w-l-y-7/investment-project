# 项目背景

- 本项目用于精选少量标的集中持有，并输出可读的投资研究报告与持仓跟踪。
- 当前硬约束：
  - 持仓标的 1–2 只；每只默认整笔买入，最多分 2 次（≤2 批）进场以对冲择时
  - 单笔投资预算区间 1 万–1.5 万、投入封顶 1.5 万（不因盈利加码超限）；预算随上一轮结果调整——盈利（达目标卖出）后上调至接近 1.5 万，亏损（红线清仓等）后下调至接近 1 万，首次进场预算由用户在区间内选定
  - 资金为闲钱；可接受套牢约 1 年，不设时间止损，市场波动与短期下跌不构成卖出理由
  - 卖出规则：平时不动；现价达到「除权调整后成本 ×(1+10%)^持有年数」即卖出落袋（目标收益率 = 年化 10%）；触发暴雷红线才提前清仓
  - 暴雷红线（触发即评估离场）：硬红线——财务造假、退市风险、被立案/监管调查、审计报告非无保留意见；基本面恶化红线——业绩大幅低于预期、主业明显恶化、大股东质押爆仓等
- 结论必须以回测数据为准，先验证再下结论，禁止拍脑袋。

# 目录约定

- `inputs/`：原始数据，只读不改；需要加工时另存副本
  - `prices/`：候选股票与标的的历史日 K（前复权，建议 3 年以上）
  - `fundamentals/`：股票池初筛与财务数据（PE/PB/ROE/股息率/净利润增速等）
  - `benchmark/`：沪深 300 等基准指数点位、无风险利率（十年国债到期收益率）
- `references/`：口径与模板（术语表、回测口径、报告模板）
- `notes/`：中间研究过程、筛选与取舍记录
- `outputs/`：最终报告、图表与权重明细

# 数据来源（优先顺序）

1. 仓库内 gs-* 技能（国信接口，需 `GS_API_KEY`）：选股 / 行情 / 资金流 / 财报
2. akshare 或券商软件导出：大批量历史日 K
3. 网站补充（手动在浏览器查询）：
   - 问财（同花顺智能选股）`https://www.iwencai.com`：用自然语言筛股票池，如"PE<20 且 ROE>15% 且股息率>3%"，可导出初筛结果 → 存 `inputs/fundamentals/`
   - 巨潮资讯网 `http://www.cninfo.com.cn`：证监会指定披露网站，下载上市公司年报/季报/公告 PDF 原文，用于基本面深读 → 存 `inputs/fundamentals/`
   - 上海证券交易所 `http://www.sse.com.cn`：查沪市（6 开头代码）公司正式披露与公告原文
   - 深圳证券交易所 `http://www.szse.cn`：查深市（000/002/300 开头）公司披露，如紫光股份 000938 的年报原文
   - 中证指数官网 `https://www.csindex.com.cn`：下载沪深 300 等指数历史点位（注册后可导出 Excel）→ 存 `inputs/benchmark/`
   - 中国债券信息网 `https://www.chinabond.com.cn`：查十年期国债到期收益率等无风险利率 → 存 `inputs/benchmark/`

# 工作规则

- 先探索目录与已有材料，再开始生成正文
- 材料不足先指出缺口，不自行臆造（历史行情缺失时不得宣称已完成回测）
- 不改动 `inputs/` 中原始文件
- 不把密钥、账号等敏感信息写入仓库或提交

# 输出要求

- 输出前给出使用材料清单
- 结果写入指定文件，并附简短状态说明
- 标的报告必须包含：买入逻辑与目标收益率、口径（区间/复权/费用）、历史最深回撤与套牢解套所需时长、暴雷红线核验、风险提示（含单票集中风险）
